# Heart Disease — Random Forest Regression

Predicts **maximum heart rate achieved (`thalach`)** from clinical and demographic features in the UCI Heart Disease dataset, using a tuned `RandomForestRegressor`.

## Why `thalach` and not `target`?

The dataset's `target` column is a binary disease label (0/1) — a classification problem. Of the continuous columns available, `thalach` has the strongest physiological relationship with the other features (age, exercise-induced angina, ST depression, etc.), making it the most sensible regression target.

## Method

1. **Data cleaning** — the raw CSV contains 1025 rows but 723 are exact duplicates; after de-duplication, 302 unique patient records remain.
2. **EDA** — correlation heatmap and target distribution.
3. **Train/test split** — 80/20.
4. **Hyperparameter tuning** — `RandomizedSearchCV` (40 candidates, 5-fold CV) over `n_estimators`, `max_depth`, `min_samples_split`, `min_samples_leaf`, `max_features`.
5. **Evaluation** — MAE, RMSE, R², compared against a mean-predictor baseline.
6. **Diagnostics** — actual-vs-predicted scatter, residual distribution, feature importances.

## Results

| Metric | Value |
|---|---|
| MAE | 14.22 bpm |
| RMSE | 18.32 bpm |
| R² | 0.28 |
| Baseline RMSE (predict mean) | 21.62 bpm |

Best hyperparameters: `n_estimators=400, max_depth=5, min_samples_split=10, min_samples_leaf=1, max_features='log2'`.

An R² of 0.28 with a ~15% RMSE improvement over the mean-predictor baseline reflects a genuine, moderate physiological signal — realistic for a clinical dataset of this size, rather than an implausibly perfect fit.

## Usage

```bash
pip install -r requirements.txt
jupyter notebook notebooks/heart_disease_random_forest_regression.ipynb
```

Run all cells top to bottom to reproduce the data cleaning, tuning, evaluation, and saved artifacts in `outputs/`.

## Dataset

UCI Heart Disease dataset (`heart.csv`), 14 columns: `age, sex, cp, trestbps, chol, fbs, restecg, thalach, exang, oldpeak, slope, ca, thal, target`.
